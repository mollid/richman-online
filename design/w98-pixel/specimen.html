使用规则（不遵守点阵就会被重采样成糊的）

  1. font-size 必须是**该字体设计字号**的整数倍。 缝合像素取 --w98-fs-pix-sm/md/lg（12 / 24 / 36px）； 秋叶圆体取 --w98-fs-qy-sm/md（16 / 32px）。两组不可混用。
  2. 关抗锯齿：-webkit-font-smoothing: none（加 .w98-pix 或 .w98-pix-qiuye 类即可）。
  3. line-height 取整数像素；letter-spacing: 0（像素字字距已算进点阵，撑开会出半像素缝）。
  4. canvas 里绘制时贴图需 scaleMode: NEAREST / image-rendering: pixelated。

1:1 像素裁决：同一句话，四种渲染

缝合像素 12px ← 主力，笔画实心纯黑骰子掷出六点，买下这块地，租金翻倍。阿福
秋叶圆体 16px ← 备选，笔画圆润但边缘带 1px 灰过渡骰子掷出六点，买下这块地，租金翻倍。阿福
秋叶圆体 32px（2 倍放大，实心 2 像素，很清晰）骰子掷出六点
系统字对照（Microsoft YaHei 12px）骰子掷出六点，买下这块地，租金翻倍。阿福

秋叶圆体自带 16px 1-bit 内嵌位图（bloc/bdat 表），但 Chrome on Windows 并不使用内嵌位图、走的是矢量轮廓 —— 实测把位图表整个剥掉再渲染， 逐像素结果完全相同。所以在 Windows 上它 16px 下会略带灰边；在会读内嵌位图的实现 （若干 Linux/Firefox 环境）上则是硬点阵。

字集浏览

为什么主力是缝合像素，秋叶圆体当备选

  1. 方舟像素 Ark Pixel 12px zh_hans（24,869 码位）缺 8 个字：「骰 窗 券 即 筑 毁 旋 姿 旅 斜」。 对一个《大富翁》来说缺「骰」是致命的，所以换掉。
  2. 缝合像素把 ark-pixel / cubic-11 / galmuri 三家开源像素字的字形并在一起，补上了这些字，还顺带带繁体。
  3. 秋叶圆体 16 血统是日本 KHドット秋葉原16（Sharp X68000 时代的 16 点阵商用位图字体）， 作者 yzdnn 增补了简繁汉字。它风格更圆润，覆盖 GB2312 全集，适合当「圆体像素」口味。
  4. 但它在 Windows Chrome 上走矢量轮廓（见上），1:1 截图比缝合像素虚，故排在第二位。 两者缺字都会回退到系统字 —— 秋叶圆体只缺「〞」「—」两个字。
