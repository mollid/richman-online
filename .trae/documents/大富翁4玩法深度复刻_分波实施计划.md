# 大富翁4玩法深度复刻 · 分波实施计划

## 一、背景（Context）

`d:\Work\richman online` 是一个 TypeScript 版《大富翁4》玩法复刻项目（pnpm monorepo：`shared` 纯规则引擎 / `server` Colyseus 权威房 / `client` React+PixiJS）。`docs/gameplay/玩法系统_游戏开发文档.md` 定义了 **161 项对标基线**（CORE/TIME/ECON/EST/CORP/CARD-01..30/ITEM-01..13/GOD-01..12/NPC/TILE-01..30(+31)/EVT/UI）。

当前实现只覆盖其中很小一部分：40 格棋盘、单一`现金`货币、21 张自定义卡（名称与文档不符且用现金购买）、4 位神明、6 支股票、2 个小游戏。距离"完整复刻玩法深度"差距很大。

本计划的目标：**按依赖顺序分波推进，逐步补齐对标基线**；每波结束都保持"可玩 + 可验证"（单测全绿、类型检查通过、浏览器可实际开局对局）。本轮先做**第一波（地基）**。

### 本轮拍板的次要点（规划代理留待确认项，直接采纳推荐）

- `STARTING_CASH` **保持 15000**：物价指数公式开局恒为 1，测试迁移面最小。（文档 ECON-06 举例的 20000 只是风味值，改动收益为零。）
- `weekday` 取**真实公历星期**（非文档备注的 `day % 7`）：TIME-05 月曆与 TIME-03/04 的 15 号/月末要求真实历法，若星期取模会与月份自相矛盾。

- `MAX_LOAN = STARTING_CASH`，一人一笔，作为可调常量（原版无明文）。

## 二、架构不变量（任何波次都不得破坏）

1. `shared` 纯函数、零渲染/网络依赖；唯一规则入口 `applyAction(state, action) => newState`。
2. **确定性回放**：RNG 状态内嵌 `GameState`；`applyAction` 路径内**严禁** `Date.now()` / `new Date()` / `Math.random()`。`new Date()` 只允许出现在 `GameRoom.onCreate` 与 `LocalHotseatSession` 构造各一次，作为 `startDate` 传入并存进 `GameState`。
3. 服务器权威：客户端只做表现，动作经 `GameRoom` 走引擎。
4. 本地热座与联机双模式共用同一套 UI/会话抽象。
5. UI 全中文；沿用 `styles.css` 既有 `.panel/.panel-title/.ghost/.mini` 体系。

## 三、第一波：地基（本轮实施）

对标范围：**TIME-01..06、ECON-01..06、ECON-09（休市）**。不含 ECON-07/08/10/11/12/13（乐透归波 6、点券商店归波 2）。

### 3.1 数据模型（`shared/src/types.ts`）

**原则**：只持久化不可推导的值；日期全量派生于「起始日期 + 流逝天数」；`PlayerAction`/`AvailableActions` 只做加法。

```ts
export interface DateSerial { year: number; month: number; day: number } // month 1-12

export interface LoanStatus {
  principal: number;         // 未还本金（无利息，到期全额归还）
  takenAtDayIndex: number;
  dueDayIndex: number;       // elapsedDays >= dueDayIndex 时强制还清
}

export interface GameCalendar {
  start: DateSerial;         // createGame 时捕获一次，之后不再读系统时钟
  elapsedDays: number;       // 开局 0；每完成一整圈 +1
}

export interface BankAccess {          // 本回合银行访问权限，回合结束清空
  canDeposit: boolean;                 // 经过或停留银行
  canLoan: boolean;                    // 停留银行当格
  cellId: number;
}
```

`Player` 新增：`deposit: number`、`points: number`（初始 3000）、`loan: LoanStatus | null`、`stockCost?: Record<string, number>`（波 5 预留，波 1 不写入）。
`GameState` 新增：`calendar: GameCalendar`、`initialCashPerPlayer: number`、`initialPlayerCount: number`（`startGame` 冻结）、`bankAccess: BankAccess | null`、`lotteryPool: number`（波 6 启用，波 1 建字段 + `pay.reason` 罚金钩子）。

`Phase`、`CellType` **本波不新增**（月结算/开奖用"自动结算 + log"，避免 phase 分支膨胀）。

**与 `round`/`turn` 兼容**：`turn`/`round` 语义不变（现有断言存活）；新增 `calendar.elapsedDays` 与 `round` 同处 +1。波 1 恒等式 `elapsedDays === round - 1`，加断言守护；波 3 起允许分离。

### 3.2 时间日历（新建 `shared/src/calendar.ts`，纯函数、零依赖）

导出：`toSerial/fromSerial/weekdayOf/isHolidayWeekday/addMonths/daysInMonth` 与 `GameDate{dayIndex,year,month,day,weekday,weekdayLabel,isHoliday,isDividendDay,isMonthEnd,daysLeftInMonth,iso}`、`gameDate(state)`、`elapsedDays(state)`。使用整型儒略式序列号算法，保证跨月/闰年确定。

**日切唯一收口点**：`advanceTurn` 绕回时 → `round+1`、`elapsedDays+1`、`onDayChange(state)`、`tickStockMarket(state)`、`state.bankAccess = null`。

```ts
const DAY_HOOKS: DayHook[] = [
  noticeHolidayHook,       // TIME-02：周六日提示 + 休市（派生值，day0 天然生效）
  dividendAndLotteryHook,  // TIME-03：15 号 → 分红+开奖（波1占位 log）
  monthEndInterestHook,    // TIME-04：月末 deposit ×1.1（有 loan 者跳过）
  loanDueHook,             // ECON-05：到期强制全额归还（先 p.loan=null 再 pay，避免递归）
];
function onDayChange(state: GameState): void { /* 逐个 hook，若 game_over 提前返回 */ }
```

- 例假日是**派生值**：`tickStockMarket` 首行 `if (gameDate(state).isHoliday) return`；`canTradeStock/canDeposit/canLoan` 均 `&& !isHoliday`；`END_TURN` 永远可用，不会卡死。
- 起始日期：`createGame(players, seed?, options?: { startDate?: DateSerial })`；`shared` 不读系统钟，调用方（`GameRoom.onCreate`、`LocalHotseatSession`）传 `new Date()`；缺省兜底固定常量 `{1980,1,1}`。

### 3.3 经济与物价指数（新建 `shared/src/economy.ts`）

```ts
export function totalAssets(state, p): number;   // 现金+存款+股票现值+不动产现值−贷款
export function propertyValue(state, prop): number; // 地价+已投入升级成本（不含指数，打断自指）
export function priceIndex(state): number;       // Σ资产 / (单人初始资金 × 存活人数)，clamp [0.01, 107374]
export function scaled(state, amount): number;   // Math.round(amount * priceIndex(state))
export function landPrice/landUpgradeCost/landRent(state, ...): number; // UI 与引擎同源
```

`priceIndex` 纯函数不缓存（客户端用 `useMemo` 做表现层缓存）。

**指数乘算点清单**（全部过 `scaled`，单点取整避免误差累积）：买地价、升级价、租金、缴税格、股票新闻金额、神明金额、小游戏赔付、手牌满补偿、变卖回收额、波 2 的抢钱/赌运。**不乘**：卡片售价、点券、股价本身、利率百分比、贷款本金、薪水。

### 3.4 支付管道与三货币

```ts
function pay(state, from, amount, to, opts?: { toDeposit?: boolean; reason?: PayReason }): void
// 现金 → 存款 → 变卖（股票→降级→售地）→ 破产；收款方按「实付 paid」入账，不凭空造钱
```

- 保留 `payCash(...)` 作为 `pay(..., { toDeposit:false })` 薄包装，压缩改动面。
- **租金入存款**（ECON-02）：`toDeposit: true`。
- **买地/升级不走 `pay`**：维持 `if (p.cash < 价) throw '现金不足'`（现金耗尽即禁止购置资产）。
- `bankruptPlayer` 扩清：`deposit=0; points=0; loan=null`（否则 `totalAssets` 为负污染指数）。
- 点券：波 1 仅落字段/初始值/UI 展示；游戏厅小游戏顺带发放少量点券，让波 2 前有点券来源。**卡片店与 21→30 卡替换全归波 2**，波 1 不动卡片逻辑。

### 3.5 银行 / 贷款

- 移动循环记录 `passedBankCell` 与 `landedOnBank`；`bankAccess = { canDeposit: passed||landed, canLoan: landed, cellId }`。
- 落格分派：若 `bankAccess.canDeposit` 为真，进入 `awaiting_action`（log"经过银行，可存取款"），否则维持原自动结算。**低风险退化**：若迁移面过大，改为"仅停留银行才开放"（波 3 扩棋盘再加独立「银行(公立)」格补路过语义）。
- 波 1 不给现有两个 `bank` 格做公私区分；`BoardCell` 加可选 `bankKind?: 'public'|'exchange'|'corporate'` 供波 3/5。
- `DEPOSIT/WITHDRAW`：校验 phase/银行访问/非例假/正整数/余额充足。
- `TAKE_LOAN`：`canLoan && !isHoliday && loan===null && amount>0`；`dueDayIndex = toSerial(addMonths(今日,+3月)) − toSerial(start)`；借期 3 个月、无利息、可提前 `REPAY_LOAN`；借贷期间不发存款利息。

## 六、风险与缓解

| 风险 | 缓解 |
|------|------|
| 确定性回放分叉（休市/利息/15 号） | `startDate` 进 `GameState`+战绩表+回放记录；`applyAction` 路径零时钟；老记录兜底固定常量 |
| 快照体积 | 36 条新闻/49 条命运/30 张卡一律放常量模块，**不进 GameState** |
| 测试迁移（最高隐藏坑） | 先固定 `startDate` + 守恒构造完成迁移，保证基线全绿，再加新功能 |
| "租金入存款"改变体感 | 改动集中在 `pay` 的 `toDeposit` 一个布尔，可一键回退 |
| "路过银行进 awaiting_action"改变节奏 | 迁移成本过大则退化为"仅停留银行可用" |
| `engine.ts` switch 膨胀（977 行） | 波 1 集中 `scaled()`；波 3 抽 `tiles.ts` handler map |
| 浮点指数误差 | 单点 `Math.round(base*index)`，上限 107374 |
