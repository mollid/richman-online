# 大富翁 Online

复刻《大富翁4》核心玩法并加入联网多人对局的原创项目。

> ⚠️ 版权说明：本项目仅复刻“玩法机制”（不受版权保护），全部美术、音乐、角色、文案均为原创，不使用任何原版素材。

## 技术栈

| 层 | 技术 |
|---|---|
| 规则引擎 | TypeScript（`shared` 包，纯函数，前后端共用） |
| 客户端渲染 | PixiJS 8（等距棋盘、棋子动画） |
| 客户端 UI | React 18 + Vite |
| 对战服务 | Colyseus（权威服务器、房间制、断线重连、掉线托管） |
| 存储 | PostgreSQL + Redis（账号/会话，后续里程碑接入） |
| 部署 | Docker Compose |

## 架构原则

1. **逻辑与表现彻底分离**：`shared` 是唯一规则实现，不依赖任何渲染/网络库。
2. **服务器权威**：联机时掷骰、买地、结算全部在 Colyseus 房间内通过 `shared` 引擎计算，客户端只做表现。
3. **确定性随机**：RNG 状态内嵌于 `GameState`，同一种子可完整回放，便于防作弊校验与录像功能。

## 目录结构

```
├── shared/    # 纯规则引擎（棋盘、回合状态机、动作、测试）
├── server/    # Colyseus 权威对战服务（GameRoom、Dockerfile）
└── client/    # React + PixiJS 客户端（棋盘渲染、UI、会话层）
```

## 开发

```bash
pnpm install          # 安装依赖
pnpm test             # 运行规则引擎单元测试
pnpm typecheck        # 全工作区类型检查
pnpm build            # 构建所有包
pnpm dev              # 同时启动客户端(5173)与服务端(2567)
```

- 客户端：http://localhost:5173（当前为本地热座模式）
- 服务端健康检查：http://localhost:2567/healthz

## Docker 部署

```bash
docker compose up --build
```

启动 PostgreSQL、Redis 与对战服务器。客户端开发模式仍用 `pnpm dev:client` 连接容器内的服务端。
