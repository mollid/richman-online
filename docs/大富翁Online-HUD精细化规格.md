# 大富翁 Online · HUD 精细化规格（hud-ac 原型）

> 对象：`design/hud-ac/`（动物森林皮肤 + 2.5D 舞台原型，不接 client）
> 本轮性质：**在既有界面上做精细化与纠错**，不改版式骨架、不接规则。
> 验证方式：脚本驱动真实 Chromium（Playwright）在 1150×1145 与 1440×900 两档实测 DOM 几何 / 溢出 / 裁切 / 遮挡，逐项截图比对。截图见 `design/hud-ac/preview/`。
> 结论：**13 处改动全部落地并复测通过**。其中 6 处是「写了但实际没生效」的隐性缺陷（贴面、持有者标色、表格、名牌、分隔标题、行情带），不是审美问题 —— 这类问题靠肉眼看原型是发现不了的，必须量。

---

## 一、结论先行

| 类别 | 数量 | 代表问题 |
| --- | --- | --- |
| **P0 缺陷（功能失效 / 信息丢失）** | 8 | 单格地名字一个都没显示；账本资产清单整张消失；六支股现价整条被挤没；持有者标色完全不可见；面板内分隔标题对比度 1.05:1 |
| **P1 观感（密度 / 层级 / 美术）** | 5 | 环心 60% 面积是空草地；名牌棕底白字与皮肤不搭；图例 8 枚 emoji chip 折两行且色值与 3D 不一致 |
| **P2 布局（极端宽高比）** | 2 | 棋盘强制 1:1，1440×900 下左右各留 ~200px 空壳；方环回退时环心面板压住 5 列格子 |

**两条通用教训**（都写进代码注释了）：

1. **`ExtrudeGeometry` 的 bevel 会把实际顶面抬到 `depth` 之上**。原型里所有按 `DEPTH`（0.5）写死的贴面 / 标色 / 棋子高度，实际都埋在格子体内 —— 这正是「单格没字」和「持有者没描边」的同一个根因。改成 `geometry.boundingBox.max.y` 实测取值。
2. **`overflow` 非 `visible` 的 flex 子项，自动最小尺寸为 0**。`.hud-tablewrap` 因此被压缩器直接压成 0 高，账本表在 900px 高的视口下整块不可见（1150×1145 下却正常，所以极易漏掉）。加 `flex: none`。

## 二、P0 缺陷清单（问题 → 依据 → 改法）

### 1. 单格地名字完全没渲染
- **实测**：3× 缩放截图下，64 格全是纯色方块，无 emoji、无名字、无地价。
- **根因**：贴面 plane 放在 `y = DEPTH + 0.012 = 0.512`，但格子带 bevel（`bevelThickness=0.05`），实际顶面在 `0.55` → 贴面在格子内部。
- **改法**：`geoTile.computeBoundingBox()` 取实测顶面 `tileTop`，贴面放 `tileTop + 0.012`；`tileAnchor`、神明金晕、棋子、影子同步改用 `tileTop`。
- **附带**：贴图字号 30 → 40px（5 字降 33、6 字降 28），名字不再截断；地价从「描边字」改成底部胶囊（浅底深字，抗底色噪声）。

### 2. 持有者标色不可见
- **实测**：图例写着「描边 = 持有者色」，但棋盘上 20 处已持有地产一块都没有标色。
- **根因**：着色块放 `y = 0.06`、描边放 `y = -0.03`，同样埋在格子体内。
- **改法**：改成在格子下半部套一圈更宽的彩色台座（`Box(TILE+0.18, 0.22, TILE+0.18)` @ `y = 0.11`），从外面能看到一圈持有者色的裙边。

### 3. 账本「资产清单」整张表消失（视口相关）
- **实测**：1440×900 下 `.hud-tablewrap` 高度 **0px**，内部 table 高 143px（即被裁掉）；1150×1145 下正常。
- **根因**：`.hud-tablewrap` 设了 `overflow-x:auto`（另一轴计算为 auto）→ 成为滚动容器 → 作为纵向 flex 子项其自动最小尺寸为 0 → 被压缩器压成 0 高。
- **改法**：`.hud-tablewrap { flex: none; overflow-x: auto; overflow-y: hidden; }`。
- **同时**：表头从「现金 / 存款 / 土地…」压成「💰现 / ✈️存 / 🏠土…」单行（9.5px，`nowrap`），数字右对齐 + `tabular-nums`；原先完整表头会竖排断成「存/款」「房/屋」两行，右侧列直接被裁。

### 4. 状态条「六支股现价」整条被挤没
- **实测**：1150px 宽下 `.hud-status__mkt` 宽度 **0px** —— 六支股一支都不显示，且没有任何提示。
- **根因**：`flex: 1 1 auto; min-width: 0`，非行情项（日期 / 物价 / 停牌 / 奖池 / 棋盘切换 / 原型标）总宽 ≈1134px > 可用 1110px，行情带作为唯一可压缩项被压到 0。
- **改法**：
  - 行情带 `flex: 1 1 34%; min-width: 200px`（保底 ≈ 两支股）；
  - 「棋盘：2.5D ⇄ 方环」从状态条挪到**棋盘右上角浮动按钮**（两种形态位置一致）；
  - 「原型 · 无规则」挪到**顶栏右端**；
  - 日期 chip 文案 `岛历第 18 天 · 月末还剩 9 天` → `岛历 18 天 · 月末 9 天`。
- **复测**：1150 → 行情带 485px / 5 支完整可见 + 右渐隐；1440 → 775px / 6 支全见。

### 5. 面板内分隔标题看不见
- **实测**：`.ac-divider__mark` 取色 `#fffdf2`（ac.css 为绿色页面底设计的浅色字），放进奶油色 `.ac-panel__bd` 后对比度 ≈ **1.05:1**。受影响：账本的「物价指数」「××路段」、岛况的「岛上驻留的神」「狱中恶人」。
- **改法**：在 `.hud-shell .ac-panel__bd` 作用域内覆写 mark 为 `--ac-brown`、虚线为 `--ac-line`（不动 ac.css 原令牌）。

### 6. 2.5D 棋子名牌被舞台圆角裁掉
- **实测**：左缘玩家名牌超出 `.d25-stage`，被 `overflow:hidden` 切掉（截图可见半截）。
- **改法**：`overlay.tick()` 里按名牌自身尺寸做边界 clamp（四边各留 8px）。

### 7. 行囊标题被硬裁成半截字
- **实测**：`🎒 阿黄 的行囊 卡片 0/15 · 道具 6（每种上限 9）` 在窄容器里被裁成「（每种」。
- **改法**：明细行 `flex: 0 1 auto; min-width: 0; overflow: hidden; text-overflow: ellipsis`；括号说明移入 `title`；行囊行加右侧渐隐 + 隐藏滚动条。

### 8. 侧栏面板标题折行
- **实测**：「📣 播报 · 第 15→71 回合，共 200 条」折两行；账本标题同样。
- **改法**：`.ac-panel__hd` 加 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis`、字号 16 → 14；文案同步压缩（`第 71 回合 · 共 200 条`、去掉标题里的 `（ECON-14）` `（UI-06）` 等编号）。

## 三、P1 观感改动

### 9. 环心 60% 面积是空草地 → 中央岛心广场
- **改造前实测**：环内 28×28 里只有 7 棵树 + 1 个池塘，中心整片空；骰子是埋在草里的 0.86 方块，在默认镜头下只是中间一个白点。
- **改法**（`world.js`）：
  - 沙径外环 `RingGeometry(6.6, 7.25)` + 广场圆盘 `CircleGeometry(6.6)`；
  - 十字小径 4 条 `Plane(2.3 × 8.0)` 从广场伸到草地边；
  - 木告示牌：立柱 + 牌面（`BoxGeometry` 六面材质，正面贴 canvas 纹理 `中央岛 / 奖池 10,753`）；
  - 骰盘 `Circle(2.5)` + 深色圈边，骰子 0.86 → **1.15**，按个数在盘内居中；
  - 高度全部按 `Box3.setFromObject(grass).max.y` 实测推（首次写死 0.545 被草地盖住，实测草地顶面 0.58）；
  - 顺带挪开压在小径上的 2 处灌木。
- **默认镜头**：`dist` 74 → 70（缩得太近 62 会切棋盘四边，实测后回调）。

### 10. 名牌美术与皮肤不统一
- 棕底白字 + 4px 描边 → **奶油底板 + 2px 主题描边 + 玩家色圆点（r=6.5）+ 软投影**；当前行动者用金底、异常状态用红底，与 ac 皮肤同一套色。

### 11. 图例：8 枚 emoji chip → 单行真色块
- **问题**：`🟩 草地：中央岛` 这类 emoji 近似色与 3D 实际色不一致，8 枚折两行很碎。
- **改法**：6 个色块直接取 `world.js` 的 `GROUP_HEX`（住宅 `#8fd07a` / 商业 `#7ec8ef` / 工业 `#c9b48a` / 科技 `#b7a6e6` / 临海 `#7fd8c8` / 金融 `#f0b96a`），加「描边 = 持有者色」「金晕 = 神明驻留」两枚示意。改皮肤时两边一起动。

### 12. 岛民行密度
- **改造前**：满宽 18px 粉色药丸 + 三行文本，一行 ≈100px。
- **改法**：每行独立小卡（`gap: 8px`、`box-shadow: 0 3px 0`），文本压成两行，进度条 18px → **6px 细条 + 百分比文字**；数值符号化（`地产 N 处 · 持股 N · 道具 N` → `🏠N · 📈N · 🧰N`）。

### 13. 侧栏面板空底
- 内容少的页签（岛民 / 岛况）原本留 ~300px 空奶油卡。改法：面板**固定占满整列**（切页签不跳高度），快照行从面板外挪到**面板底部钉住**（`.hud-panelfoot`，虚线分隔），侧栏成为一块完整窗。

## 四、P2 布局改动（极端宽高比）

### 14. 棋盘强制 1:1 导致宽屏空壳
- **改造前**：`.d25-stage` 写死 `aspect-ratio: 1/1` + `height:100%`。1440×900 下舞台只有 ~490px 宽，棋盘列 ~1030px，**左右各留 ~200px 空壳**。
- **改法**：
  - 舞台改为铺满容器（去掉 `aspect-ratio`）；
  - `world.js` 加取景补偿 `frameScale()`：竖向 fov 固定，画面比参考更窄时按 `1/aspect` 等比退远，否则棋盘左右会被切；
  - **≥3:2 宽画面**时图例从「棋盘下一条」切成「棋盘右侧竖排导轨」（`.hud-board--wide`），把空档吃掉，图例本身也更好读；跨越断点靠 `matchMedia('(min-aspect-ratio: 3/2)')` 触发整块重排。

### 15. 方环回退时环心压住格子
- **改造前**：环心内容宽于 12/17 环宽，面板向右溢出压住 5 列格子。
- **改法**：`.hud-center > * { max-width: 100% }` + 神明卡限宽 88px + 环心改 `overflow: hidden` 与垂直居中；按钮区新增一行 `.hud-flatbar`（方环四角都是格，浮动按钮会压格，不能挂角上）。
- **复测**：环心面板覆盖格子数 **5 列 → 0/64**。

## 六、没做 / 已知限制

1. **没换掉 emoji 占位**：格面图标、棋子、骰子点、行囊道具仍是 emoji。进产品需换成图集资源 —— 这一步需要出图，本轮未做。
2. **中文圆体缺字**：`--ac-ui` 走 M PLUS Rounded 1c，中文回落系统黑体。属字体方案问题（需内嵌中文圆体子集或换字体），非本轮范围。
3. **斜 45° 轴测下单格仍偏小**：默认镜头下 40px/格、字号 ≈10px，可读但不算舒适；`斜 45°` 预设下更小。真要舒适需把「镜头距离 + 棋盘尺度」一起定死（或做镜头分级：全局 / 半区 / 单格三档）。
4. **宽屏横向空间仍未用满**：棋盘是方的、高度已顶满，横向必有剩余。本轮用图例导轨补掉了 ~158px，剩余部分靠舞台自身的渐变底填充。要彻底解决需把 dock 的「选中格 + 行囊」拆到棋盘右侧（属版式改动，不在精细化范围）。
5. **未接真实规则**：点击仍只做表现。快照来自 `tools/dump-snapshot.mts`，第 71 回合。
6. **`prefers-reduced-motion` / 键盘可达性**：原实现已有，本轮只做同步维护，未回归测试。
