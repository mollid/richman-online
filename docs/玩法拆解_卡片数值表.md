**字段语义**（代码用法实证）：

- `+1 价格`：点券计价。踩城自动攻击按"预算 ≥ 价格"筛选
- `+3 类别`：双重用途——①踩城自动攻击筛选；②**主动用卡的等级门槛**（见 §二）
- `+0 b0`：卡的价值单位。搶奪卡抢到一张卡时，受害者按 b0 付点数补偿
- `+2 b2`：2 = 对玩家发动的攻击类

## 二、主动用卡三表机制（本轮核心成果）

同一卡 ID 同时索引三张表：

```
卡 ID (0..30)
  ├─ 卡片静态表   0x47fdee (8B/条)        → 价格/等级门槛
  ├─ AI 决策表    0x475328 (4B/条)        → 用不用 + 选目标
  └─ 效果执行表   0x475d60 (4B/条)        → 真正执行
```

> Ghidra 反编译里的 `DAT_00475324` / `DAT_00475d5c` 标号各偏 -4 字节，真实表基址如上（按購地/換地/換屋/轉向/改建五卡语义四重验证对齐）。

**分发入口 FUN_0041e69e(cardId)**：

1. 等级门槛：`N[card].类别 - 玩家等级(0x496b7f+me*0x68) > 1` → 不能用
2. 差 1 级 → 随机数 `% 3 == 0`（**1/3 概率越级用卡**）；差 ≤0 → 直接过
3. 通过 → 调 AI 决策表[card]，决策函数返回 1 = 用，并把目标写 `_DAT_0048be58 = 0x8000 | 1<<玩家`（FUN_0041e6f2(0) 读回；人类用卡时改弹 0xe0c0xxx 选择 UI）

**道具分发器 FUN_00420e9a(propId)**（propId 0 = 機器娃娃，1 = 路障…）：与卡分发器同构——类别字段 `0x47fee1 + propId*8`（= N[30+propId].类别）、决策表 `0x4753a0 + propId*4`，同样有等级门槛 + 1/3 越级。

**AI 主循环 FUN_00441baa**：遍历 AI 手牌（最多 8 张）逐张问分发入口；第一张"决定用"的立即执行：演出 FUN_00441f73(cardId) → 执行表[card]()。

## 三、逐卡效果执行公式（执行函数全精读）

### 经济类

| 卡      | 公式                                                                                                                          |
| ------ | --------------------------------------------------------------------------------------------------------------------------- |
| **均富** | 全场存活玩家现金各自设为平均值 Σ现金/人数；超出均值者按 `(现金-均值)/100` 付点数给用卡者（FUN_0040df69 = 点数转账）                                                    |
| **均貧** | 与指定玩家平分：`avg=(我+他)/2`，双方现金=avg；对方更富则付 `(他-avg)/100` 点数                                                                      |
| **購地** | 总价 = `(基础地价 + 层数×加盖价) × 物价倍数`；现金直付原主（FUN_0041d2c6）；原主另得**点数补偿 = (层数+2)/5 × 基础地价 × 物价**；归属字节 0x19 改为自己；现金不足弹"不足"提示（0x46530c） |
| **拍賣** | 脚下地块：原主得 `(层数+2)/5 × 地价 × 物价` 点数；归属清零。人类弹拍卖 UI（FUN_0043bde5）                                                                |
| **查稅** | 指定玩家：金额 = ROUND(资产 × 随机比例)（比例在 FPU 栈，常量待精查，实测约 1~2 成）；先扣 `金额/100` 点数（防免罪判定），再现金转账 target→me；有同盟(0x14)/医院(0x13)状态时可转嫁他人付钱    |

### 建筑类

| 卡      | 公式                                                               |
| ------ | ---------------------------------------------------------------- |
| **天使** | 指定自己街区：同街每块地层数 +1（上限 5 层；0x4c=封顶标志跳过）；地标则 0x40b110(tile)&0x80 直升 |
| **惡魔** | 指定街区：全部地块层数、类型清零；原主每层获 **30×物价** 点数补偿                            |
| **怪獸** | 指定**单块**地：建筑拆光（Panel 0x22d 怪獸演出 500ms）；原主获 `层数×30×物价` 点数         |
| **拆除** | 指定单块地：层数 -1（若 0x18 空地类则连类型清零）；原主获 **30×物价** 点数                   |
| **改建** | 脚下空地：类型字节 0x18 翻转/重选（人类 UI 选 0-3）；改成 0 或 3 类且层数>1 时重置 1 层        |
| **換地** | 同类地块（地段↔地段 / 地标↔地标）互换归属字节 0x19                                   |
| **換屋** | 两地块整体数据互换（FUN_0040b4f8，建筑层数跟着走）                                  |
| **漲價** | 指定街区全部地块 0x4b = 0x50（涨价状态 → 配合新闻"公告地價調漲３０％"）                     |
| **查封** | 指定地块 0x4b = 0x51；若目标区块 0x0c==4（企业城）→ 0x0f 停业标志清零                 |

### 数值常量速查

- 拆迁点数补偿：**30 × 物价倍数/层**（惡魔/怪獸按层数乘，拆除固定 1 层价）
- 購地/拍賣补偿系数：**(层数+2)/5**（浮点常量 0x46531c=2.0、0x465320=5.0）
- 冬眠/夢遊/陷害点数：**150 × 物价倍数**（0x96）
- 冬眠时长 **5 回合**；同盟时长 **7 天**
- 越级用卡概率 **1/3**（差 1 级时）

- **烏龜卡 AI = 0x420970**：读前方 3 格（0x48b8b4）地块归属/地价——自己地盘连片或对方踩贵地时才用

## 七、实体系统与踩格结算（路障 / 地雷 / 定時炸彈 / 神明）

### 7.1 实体表 0x496d08（0x18B/条 × 46 槽，共 0x450B）

| 偏移 | 字段       | 说明                                               |
| -- | -------- | ------------------------------------------------ |
| +0 | u8 类型    | **地图加载时从静态表 0x47ed3c 逐槽预填**（FUN_00407ad2），放置函数不写 |
| +1 | u8 精灵ID  | FUN_00407a8c 按邻接地块外观计算                           |
| +2 | u16 tile | 所在地块（=0 表示空槽）                                    |
| +4 | u8 计时    | 定時炸彈倒计时用                                         |
| +5 | u8 归属    | 归属玩家+1                                           |

**静态类型表 0x47ed3c（46 字节，dump 实证）**：

```
槽 0-13  : 01 02 03 04 05 06 07 08 09 0a 0b 0c 0d 0e   ← 神明/事件点各 1 槽
槽 14-15 : 0f 0f                                        ← 神明出现点 ×2
槽 16-25 : 10 ×10   ← 路障，场上最多 10 个
槽 26-35 : 11 ×10   ← 地雷，场上最多 10 个
槽 36-45 : 12 ×10   ← 定時炸彈，场上最多 10 个
```

"槽位区间=类型"由此烙死：FUN_0040e033(type,…) 的 switch 只是把类型码翻译成槽区间（0x10→0x10-0x19、0x11→0x1a-0x23、0x12→0x24-0x2d、0xf→0x0e-0x0f、神明 1-14→槽 0-13），在区间内找空槽（+2==0）放置。

**开局随机布点**（FUN_00407ad2 行 61-76）：随机放 5 个神明（类型 1,3,5,7,9 各一）+ 得卡点 0xd ×1 + 点数点 0xe ×1。

### 7.2 tile+0x24 u32 三段位段（实体挂接点）

```
&0x0000ff   tile 自身属性（0xe = 医院类格）
&0x000f00   同格玩家位图
&0xff0000   实体槽号+1（>>0x10 后即 local_14）
```

放置时 `tile+0x24 |= (slot+1)<<16`（0x40e033 行 55）；炸彈挂身时清 `tile+0x26 = 0`（即清掉第三段）。

**玩家身上实体**：`0x496ba8[me]` = 挂身实体槽号+1（神明附身与定時炸彈共用一个字段）。

### 7.3 踩格结算引擎 FUN_0041b42d（每踩一格调用）

开头读 tile+0x24 三段 + 实体类型 local_1c（`0x496d08[(slot-1)*0x18]`），然后：

**① 機器娃娃清障（DAT_0049910c==8 行走单位）**：踩到任何实体格 → `0x40fafd(slot,…)` + `0x40e14d(slot)` 清除后 return（清除而非捡走，实证）。

**② 身上实体倒计时（0x496ba8[me] != 0，行 85-116）**——定時炸彈的核心：

```c
slot = 0x496ba8[me] - 1;
0x496d0c[slot] -= 1;              // 每走一步 -1
if (--timer == 0) {               // 归零 → 爆炸！
    演出 0x482362（爆炸动画）
    0x40e14d(挂身槽)               // 清实体
    if (tile+0x20 u16 != 0) 0x40ab4a(该值, 0);   // 波及处理
    0x40cd07(me)                   // 摔倒演出
    消息框 Panel 0x20d
    DAT_0048baf8 = 0;              // 剩余步数清零（当场停下）
    0x43ec3f(me, 5);               // 送医院 5 天，return
}
if (同格有别人 && 那人 0x496b7d!=0 && 其身上无实体) {
    0x496ba8[他] = 0x496ba8[me];   // ★炸彈转移给别人！
    0x496d0d[slot] = 他+1;         // 归属改
    0x496ba8[me] = 0;
    演出 0x482362;
}
```


**③ 踩到地上实体 switch(local_1c)**：

| 类型 | 效果（反汇编实证） |
|---|---|
| 1-10, 0xc | 神明附身 `0x40ead7(me, tile, slot)`（走完停留时触发） |
| 0xb | **摔傷点**：骑载具（0x496b79!=0）→ 演出 Panel 0x228 后**无事**（载具挡下）；步行 → 摔倒 0x40cd07 + Panel 0x214 + 绊停 + **0x43ec3f(me,3) 送医 3 天** |
| 0xd | **得卡点**：FUN_00445ada(me) 抽卡 → 演出 0x48237a → 清实体 → 0x44f230(me, N[卡].b0) 入手 |
| 0xe | **点数点**：`0x496b98[me*0x34] += 500`，+角色语音 |
| **0x10 路障** | 清实体 0x40e14d → `DAT_0048baf8 = 0`（剩余步数清零=**当场绊停**）+ 语音。**不送医不扣钱**。神明单位(4)踩中→额外 FUN_00445a4d(主人,2) |
| **0x11 地雷** | 清实体 → 摔倒 0x40cd07 + Panel 0x20d + 语音 → 绊停 + **0x43ec3f(me,3) 送医 3 天**。神明单位踩中→FUN_00445a4d(主人,3) |
| **0x12 定時炸彈** | **不立刻爆，挂到自己身上**：`0x496ba8[me]=槽+1`、实体归属改自己 `0x496d0d[slot]=me+1`、**计时重置 0x496d0c[slot]=0x26（38 步）**、`tile+0x26=0` 从地块摘除 + 语音。之后每步 -1，见②爆炸/转移。条件：身上无实体才挂。神明单位踩中→清实体+FUN_00445a4d(主人,4) |

> 结论：**踩中判定全表**——路障=绊停无害化；地雷=立刻炸伤送医 3 天；定時炸彈=挂身倒计时 38 步，期间同格相遇会甩锅给别人，倒计时归零爆炸送医 5 天（比地雷重）。三者均被機器娃娃清除。
