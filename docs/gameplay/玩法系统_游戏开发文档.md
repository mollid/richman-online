## 1. 核心玩法循环（CORE）

### 1.1 一句话定义

> 玩家轮流掷骰在地图谱格上移动，通过**买地—盖楼—收租**、**炒股—经营公司**、**刷卡害人**三条线累积总资产，直到其他玩家全部破产。

### 1.2 对标项

| 编号 | 项目 | 规格 / 数值 | 实现要点 | 优先级 |
|------|------|-------------|----------|--------|
| `CORE-01` | 回合制推进 | 所有角色各行动一次（一整轮）即算**一天**；玩家依次行动 | 主循环：`for player in turn_order: run_turn(player)`；维护 `global_day` 计数器 | P0 |
| `CORE-02` | 单回合流程 | ① 结算附身/状态 → ② 掷骰 → ③ 动画移动 → ④ 落格结算 → ⑤ 回合结束事件 | 状态机：`TURN_START → ROLL → MOVE → TILE_RESOLVE → TURN_END` | P0 |
| `CORE-03` | 移动力（骰子数） | 步行 **1 颗**；持机车 **2 颗**；持轿车 **3 颗**。可自选本次使用几颗骰子 | 移动前弹出骰子数选择；步数 = n 颗骰子点数之和 | P0 |
| `CORE-04` | 胜负条件 | 对手全部倒闭（破产）即获胜；玩家中途可**认输投降**退出 | 结算顺序：先判破产再判胜负；投降走"死神附身"特殊流程 | P0 |

### 1.3 单回合状态机（参考实现）

```
TURN_START
  ├─ 处理附身神明的每日显灵效果
  ├─ 处理住院 / 坐牢 / 梦游 / 冬眠 / 停留 等状态（跳过或限制行动）
  ↓
ROLL            （选择骰子数 → 掷骰；乌龟卡期间强制 1 步）
  ↓
MOVE            （逐格推进；触发路障／地雷／恶犬／恶人／宝箱）
  ↓
TILE_RESOLVE    （按格子类型分派：空地／商业地／公司／银行／监狱／医院／商店／小游戏…）
  ↓
TURN_END        （跨日结算：日→周→月；15 号分红／乐透；月末银行利息）
```

## 3. 经济与金融系统（ECON）

### 3.1 三种货币与资金层级

| 货币 | 获取 | 用途 | 约束 |
|------|------|------|------|
| **现金** | 收租、卖资产、股票、事件 | 买地、付租金、罚款、额外花费 | **现金用尽后不能购买任何资产**；后续支出自动从存款扣 |
| **存款** | 银行存入、收租自动入账 | 生息（月末 +10%）、自动扣款 | 股票收支由银行自动转扣 |
| **点券** | 初始配额、游乐场（点券格 +10/+30/+50、宝箱等） | **卡片与道具的唯一兑换货币**（不能用现金买） | — |

### 3.2 对标项

| 编号 | 项目 | 规格 / 数值 | 实现要点 | 优先级 |
|------|------|-------------|----------|--------|
| `ECON-01` | 现金 | 支付买地/租金/杂项；耗尽则禁止购置资产，其余支出转由存款扣 | 支付管道：`pay(amount)` 先扣现金，不足再扣存款 | P0 |
| `ECON-02` | 存款 | 月末 +10%；对手停在你的地，租金**自动存入你的户头** | 挂租金收款事件 → 入存款 | P0 |
| `ECON-03` | 总资产计算 | `总资产 = 总资金 + 股票现值 + 不动产现值 − 贷款` | 每回合计算并缓存，用于物价指数 | P0 |
| `ECON-04` | 银行存取 | 路过银行可存/提现金；停留银行当格可贷款 | 需区分"路过"与"停留"两种触发 | P1 |
| `ECON-05` | 贷款 | 借期 **3 个月**，到期**全数归还**；**无利息**；借贷期间银行**不发存款利息**；可提前还款 | 状态：`loan_principal / loan_due_day` | P1 |
| `ECON-06` | 物价指数 | 以**所有人的总财产平均值**为基准；开局为 **1**；平均值加倍 → 指数上升；**过路费、事件金额、地价**随之倍数上涨 | `index = f(avg_assets)`；所有金额结算统一乘 `index` | P1 |
| `ECON-07` | 保险 | 踩到保险公司**强制**签约；显示"保险有效剩余天数" | 强制触发，不可拒绝 | P1 |
| `ECON-08` | 乐透 | 自选号码，**现金 1000 元**投注；每月开奖；无人中奖则**奖金累积**；运气/事件等意外损失的钱也**汇总进奖池** | 全局奖池变量 `lottery_pool`；罚金钩子累加 | P1 |
| `ECON-09` | 股票买卖 | 随时可买卖；**例假日休市** | 与 `TIME-02` 联动的市场开关 | P1 |
| `ECON-10` | 股票指标 | 总市值（现值）、成本（投资成本）、经营权（控股公司数）三项独立展示 | 持仓模型：`{company: {shares, cost}}` | P1 |
| `ECON-11` | 点券商店 | 卡片店/道具店以点券兑换；踩到商店格先进入**卡片店**界面，可切往**道具店** | 统一商店 UI，两个货架 | P1 |
| `ECON-12` | 牌/道具持有上限 | 卡片：**最多 15 张**，额满再得须**选择舍弃**；道具：**每种最多 9 个** | 容量校验 + 舍弃弹窗 | P1 |
| `ECON-13` | 拍卖 | 触发：有人倒闭 / 有人用拍卖(售地)卡 / 事件发生 / 银行拍卖土地；**有现金者**可参与，**价高者得**，无现金不得参与 | 拍卖器：触发源枚举 + 出价轮询 | P1 |
| `ECON-14` | 资产/地产/股票清单 | 三个清单查询：资产（现金/存款/土地/房屋/股票/总值）、地产、股票明细 | 三个只读报表视图 | P2 |

## 4. 不动产与建设系统（EST）

### 4.1 两类用地

| 用地 | 购买 | 建设 | 升级上限 |
|------|------|------|----------|
| **住宅用地（空地）** | 公定价格购买 → 成为"许可建地" | 直接加盖房屋 | **5 级**（越高租金越多） |
| **商业用地** | 公定价格购买（首次） | **下次**走到该地才可选建设：公园 / 购物中心 / 旅馆 / 加油站 / 研究所 | 除公园、加油站外 **5 级** |

### 4.2 对标项

| 编号 | 项目 | 规格 / 数值 | 实现要点 | 优先级 |
|------|------|-------------|----------|--------|
| `EST-01` | 购买空地 | 前进至空地，依**公定价格**购买，成为许可建地 | 地价表驱动 | P0 |
| `EST-02` | 住宅加盖 | 可加盖 **5 个等级**，等级越高租金越高 | `level 1..5` | P0 |
| `EST-03` | 路段联合租金 | **同路段的产业租金联合计算**；买下整路段并盖高楼 = 黄金路线 | 按"路段分组"聚合所有者的产业再加成 | P0 |
| `EST-04` | 连锁店 | 用**改建卡**可将住宅改建为连锁店，也可改回一般建筑；改建后**不能再加盖** | 互斥状态：`NORMAL ⇄ CHAIN` | P1 |
| `EST-05` | 连锁店收费规则 | **不论座落何处收费相同**；租金**不与同路段联合计算**，**以店面总数计算**；单店营收远低于其他建筑；开店越多收益越大 | 全局连锁店计数 → 单店营收曲线 | P1 |
| `EST-06` | 商业用地购置 | 走到商业用地依公定价格购买（**首次只能买地，不能建**） | 两阶段状态：`OWNED_EMPTY → BUILT` | P1 |
| `EST-07` | 商业建设项目 | 5 种：公园、购物中心、旅馆、加油站、研究所 | 枚举 `FacilityType` | P1 |
| `EST-08` | 公园 | 公共开放设施；建费低廉；**不向使用者收取任何费用**；**不能再升级**；是玩家可落脚的安全地带 | 零收费 + 不可升级 | P2 |
| `EST-09` | 研究所 | 私人研究机构，**不向路过者收费**；**每升一级多开发一种道具**；业主走到可选研发项目，不同项目**研发时间不同**，时间到道具入栏 | 研发队列：`{item, remain_days}` | P1 |
| `EST-10` | 研究所研发序列 | Lv1 **机器工人** → Lv2 **时光机** → Lv3 **传送机** → Lv4 **工程车** → Lv5 **核子飞弹** | 固定映射表 | P1 |
| `EST-11` | 加油站 | 踩到须按**行走步数 × 交通工具等级**支付加油费；**无法升级** | 费用公式 | P2 |
| `EST-12` | 购物中心 / 旅馆 | 购物中心：转轮盘决定消费金额；旅馆：须休息若干天，转轮盘决定**消费金额与休息天数** | 轮盘随机 + 强制停留 | P2 |

> **扩张手段汇总**：购地卡、换地卡、换屋卡、停留卡、路障等卡片道具；以及拍卖与「交易」指令买卖房屋。

## 5. 公司企业系统（CORP）

### 5.1 通用规则

1. 公司在地图上固定地点，**开局即拥有建筑物**；各公司**初始资产值与股票面值不同**。
2. 停在某公司行号：若**经营权属他人** → 你须按该公司消费方式缴费，费用充作**累积盈余**；付费后可**认购股份**，每次**最高 1000 张**。
3. **持股比任何人都多** → 取得**经营权**，成为董事长，享**免付费特权**。
4. 他人持股超过你 → 电脑**自动移交经营权**给持股最多者。
5. **持股数相同** → 经营权归**"先拥有者"**。
6. 每月 **15 号**：按持股比例**发放盈余**给股东；**公司亏损则负债由股东按比例承担**。

### 5.2 对标项

| 编号 | 项目 | 消费 / 规则 | 实现要点 | 优先级 |
|------|------|-------------|----------|--------|
| `CORP-01` | 通用停留结算 | 依公司类型分派；缴费计入累积盈余；可认购股份（≤1000 张/次） | 策略模式，每公司一个 handler | P1 |
| `CORP-02` | 经营权判定 | 最大持股 + 同票先到先得；董事长免付费 | 每回合重算 `majority_holder` | P1 |
| `CORP-03` | 航空公司 | **转轮盘**决定出国旅游天数并付费；**出国期间不能收过路费** | 强制离场状态 | P2 |
| `CORP-04` | 饭店 | 走到即转轮盘决定**休息天数**与**消费金额** | 强制停留 | P2 |
| `CORP-05` | 电脑公司 | 走到须付**电脑使用费** | 定额/比例收费 | P1 |
| `CORP-06` | 保险公司 | 踩到**必须签约**，转轮盘决定**投保天数**并付保费 | 强制 | P1 |
| `CORP-07` | 汽车公司 | 付**保养费**；**没开车就不用给钱** | 依赖是否持有车辆 | P2 |
| `CORP-08` | 石油公司 | 付**加油费**；**没开车就不用给钱** | 同上 | P2 |
| `CORP-09` | 银行（公司） | 功能与公立银行相同；董事长可**特别融资**周转现金，可周转额 = **其他玩家存款总和**；周转期间**停止发息**；超出额度致客户权益受损须**立即还清**；董事长换人时上任董事长的周转融资也须**立即还清** | 复杂约束，建议单独模块 | P1 |
| `CORP-10` | 水力公司 | 依**拥有土地总笔数**付水费 | 计费挂土地数 | P2 |
| `CORP-11` | 电力公司 | 依**所有房屋、连锁店、建设的级数总和**付电费 | 计费挂建筑等级总和 | P2 |
| `CORP-12` | 百货公司 | 与公立百货相同；**经营者（董事长）进入时，公司赠送一张卡片或一项道具** | 触发条件 = 董事长 + 进入格 | P1 |
| `CORP-13` | 房地产公司 | 走到此地可**任选一处加盖一层房屋**，之后依该地地价**收取施工费** | 选地 UI + 施工费结算 | P2 |

## 6. 卡片系统（CARD-01 – CARD-30）

**通用规则**：全游戏共 **30 种**卡片；每人**最多持有 15 张**，额满后再获得其他卡片**必须选择舍弃**。卡片**必须以点券购买**，不能以现金购买。

| 编号 | 名称 | 原价(点) | 功能 | 使用范围 / 时机 | 注意 / 反制 |
|------|------|---------|------|----------------|-------------|
| `CARD-01` | 均富卡 | 200 | 将**所有人**的现金平分 | 任何时候，等最佳时机 | 现金最多时慎用 |
| `CARD-02` | 均贫卡 | 200 | 将**指定对手与自己**的现金平分 | 对手在地图视窗范围内 | 现金多于对方时慎用 |
| `CARD-03` | 购地卡 | 35 | 以**市价强制收购**别人的土地（连房子一并取得） | 走到别人的地时 | 无法对公司企业使用；现金不足会失败 |
| `CARD-04` | 换地卡 | 25 | 以**地换地**（空地换大楼） | 以当格土地换视窗内其他土地 | **商业换商业、住宅换住宅**；不可对公司企业 |
| `CARD-05` | 换屋卡 | 20 | 以**屋换屋**（平房换大楼） | 以当格土地上的房屋换视窗内其他房屋 | 同类型互换；不可对公司企业 |
| `CARD-06` | 转向卡 | 20 | 改变人物行进方向，**180° 向后转**（P1-1 已实现） | 视窗范围内所有人 | 无 |
| `CARD-07` | 改建卡 | 15 | 住宅建筑 ⇄ 连锁商店互转；也可**变更商业用地设施项目** | 走到任何有建筑的土地上 | 不可对公司企业 |
| `CARD-08` | 拍卖卡 | 20 | **拍卖任意一处土地**，所得归使用者 | 走到的土地上 | 不可对公司企业；**使用者不参与该拍卖会** |
| `CARD-09` | 天使卡 | 160 | 指定一处土地 → **整个路段的房屋都加盖一层** | 地图视窗范围内的土地 | 无法加盖公司企业 |

## 附：拆解方法留档

| 步骤 | 做法 |
|------|------|
| 1 | `help.mkf` 为标准 MKF 容器：文件头 4 字节 LE 索引偏移 → 尾部 N 个 u32 分块表；每块 16 字节头（`u32 u, c, f2, f3`）+ body |
| 2 | 本例 100 块**全部未压缩**（`u == c`），故 **无需**解压器，直接按 `BIG5` 解码即得繁体帮助文本 |
| 3 | 编号 `[01]`–`[99]` 顺序与 help 菜单一致；`[57]`–`[86]`= 30 张卡片、`[87]`–`[99]`= 13 件道具 |
| 4 | 与公开卡片代码表（`01`–`1E`）交叉验证，逐项命名确认 |

> 复用工具：本地 skill `mkf-resource-parser`（`parse_mkf.py` 盘点/提取；`mkfdec.exe` 解压压缩块）。
