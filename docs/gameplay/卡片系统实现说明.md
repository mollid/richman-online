# 卡片系统实现说明（P1，2026-09-23）

## 数据来源（权威，零编造）

- 30 张卡片（CARD-01..30）的名称 / 原价点券 / 功能 / 使用范围 / 反制关系，全部取自
  `help.mkf` 内建帮助 `[57]`–`[86]`（游戏本体权威），与公开卡片代码表逐项互证，
  详见 `docs/gameplay/玩法系统_游戏开发文档.md` §6。
- 数据文件：`game/logic/card_data.gd`（`RichCardData`），30 条全量入库，
  `supported` 开关控制哪些卡当前生效。

## 本轮生效范围：26 / 30 张

**生效**：均富、均贫、购地、天使、恶魔、怪兽、拆除、抢夺、停留、冬眠、梦游、陷害、
免费（自动）、免罪（自动）、查税、涨价、查封、同盟、乌龟、转向、换地、换屋、改建、拍卖。

**未开放（数据已入库，等对应系统）**：复仇/嫁祸（待事件联动，Step 6）、
红卡/黑卡（待股票系统）。

## V0 简化点（后续精修）

1. **免费卡自动抵用**（原版玩家自选时机）。
2. **梦游**：只停留不乱走（无 AI 巡游）。
3. **同盟**：只做互不收租，不做联合收费 / 背盟检测。
4. **均富 / 均贫的抽成已补**（D-05①②）：拉平之后，原本高于均值的人再付 `(现金−均值)/100` 给用卡者；
   余数仍归使用者（D-20）。均贫只在**对手更富**时抽，用卡者自己更富不倒抽。
5. **购地款按原版公式**（D-05③）：`(层+2)/5 × 基础地价 × 物价`，替换掉旧的"含各级升级费的现价"
   （500 地价的 2 级地：旧 800 → 新 400；满级地约 2000 → 700，这张卡因此明显变强）。
5. 涨价/查封 5 天含使用当天；同盟 7 天同口径。

## 界面操作

- 右侧面板新增 **用卡** / **卡片店** 按钮（骰子选择阶段和买地/加盖阶段都能用）。
- 卡片店：30 张卡列表（未开放的灰掉），点卡片买，扣点券。
- 用卡：点卡片 → 需要目标的弹 1P-4P 按钮；街道/建筑类的**直接点地图上的格子**选目标。
- 状态栏显示：`点券 X｜手牌 X/15`。
- 乌龟卡生效的玩家掷骰时自动变成「只能走 1 步」。
