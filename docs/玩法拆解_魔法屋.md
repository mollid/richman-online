## 一、怎么触发

- 走到**魔法屋格**并停下（正常骰子停留即可触发）。
- **住院 / 坐牢状态踩到不触发**（状态保护）。
- 人类玩家和电脑都会触发，结算规则完全相同。

## 二、进入后看到什么（按时间顺序）

### 玩家（人类）

1. 切入**魔法屋选择界面**：魔法屋主人立绘 + 选择菜单（布局 0x4757E7）。
2. **玩家根据界面给出的目标条件，自选要施放的事件（魔法）**——目标谁、施什么法，都由玩家决定。
3. 确认后系统按所选条件筛出中招者，弹出结果对话框（两行：目标标语 + 效果名，例：`房屋最多的人` ＋ `立刻坐牢三天`），随后播放对应演出。

### 电脑

全自动：随机抽条件（无合格者就重抽）→ 随机效果；**候选名单含自己时强制改成「得一張卡片」自保**。

### 共通

确认后弹出对应演出（进监狱画面 / 加盖动画 / 得卡画面 / 拆房画面……）。

## 三、"整谁"——12 种目标标语

系统先随机决定"整哪种人"，凡是符合条件的玩家**全部中招**（可多人同时）：

| # | 屏幕标语 | 谁会中 |
|---|---|---|
| 1 | 財產最多的人 | 总资产（现金+存款+地产折价）最高者 |
| 2 | 土地最多的人 | 名下地块数最多者 |
| 3 | 房屋最多的人 | 名下有房屋的地块数最多者 |
| 4 | 現金最多的人 | 手头现金最多者 |
| 5 | 存款最多的人 | 银行存款最多者 |
| 6 | 點券最多的人 | 点券最多者 |
| 7 | 走路的人 | 没有骑任何载具的人（全员可能中） |
| 8 | 騎機車的人 | 当前骑机车的人 |
| 9 | 開汽車的人 | 当前开汽车的人 |
| 10 | 神明附身的人 | 身上有神明的人 |
| 11 | 所有男生 | 男性角色全部 |
| 12 | 所有女生 | 女性角色全部 |

**细则**：
- 玩家自选条件；最高值**并列**时，并列者一起中招。
- 所选条件下没有合格的人（例如没人骑机车）→ 需要重选（AI 则自动重抽）。
- 「候选含自己 → 强制得卡」的**自保逻辑仅限电脑**；玩家自己选，想把自己算进去也是自己的决定。

## 四、"施什么法"——11 种魔法

确定目标后施放魔法。**玩家自选要施放哪种**（电脑随机抽）。有好事也有坏事：

### 坏事（对目标）

| 屏幕效果名 | 玩家遭遇 |
|---|---|
| **變賣所有卡片** | 手牌全部自动卖掉，换成点券（点券归目标自己，等于清空手牌） |
| **抽取命運三張** | 连续抽 3 次命运（相当于连踩 3 格命运） |
| **立刻坐牢三天** | 目标立即入狱 3 天，并记账 **90×物价** 点券给踩魔法屋的人 |
| **原地停留一回合** | 目标下回合原地停留 |
| **就地拆除房屋** | 目标脚下格的房屋被拆掉（有拆房动画） |
| **住院檢查三天** | 目标立即送医院 3 天，并记账 **90×物价** 点券给踩魔法屋的人 |

### 好事（对目标）

| 屏幕效果名 | 玩家遭遇 |
|---|---|
| **得一張卡片** | 目标获得一张随机卡片 |
| **就地加蓋房屋** | 目标脚下格免费加盖一层（仅一般地块） |
| **存入所有現金** | 目标现金全部自动转成存款（防小偷，中性偏好） |

### 中性

| 屏幕效果名 | 玩家遭遇 |
|---|---|
| **向後轉** | 目标行进方向反转（下回合往回走） |

### 隐藏

| 效果 | 说明 |
|---|---|
| 拍賣當格土地 | 代码存在但**不在随机池**，正常游戏遇不到 |

## 五、关键规则速记

1. **玩家拥有完全选择权**：挑目标条件 + 挑魔法，想把谁送进监狱（包括理论上把自己算进去）都由自己决定；电脑则随机+自保（候选含自己强制改「得一張卡片」）。
2. **坐牢/住院的 90×物价点券记在踩屋者名下**——踩魔法屋=替自己惩罚对手并收赔偿。
3. 变卖类（卡片/道具）不产生损失——所得点券归目标，只是清空手牌/道具栏。
4. 抽取命運三張是最凶的一档（三件命运事连着来）。
5. 多人并列时人人有份；效果对每个目标**依次**结算。
6. 「所有男生/所有女生」按角色性别判定，与玩家操作无关。
