# 新闻事件池拆解报告（GAP #7 已补）

> 拆解日期：2026-09-23
> 方法：不直接逆向 rich4.exe 事件数据段，而是**借用开源逆向项目 mytbk/rich4 的带注释反汇编**（asm/rich4_news.asm + csrc/news.c，GPL-3），从「跳转表 + BIG5 字符串表 + 效果函数常量」三处交叉还原。
> 落地：`game/logic/news_data.gd`（全量 36 条）+ `game/logic/game.gd`（抽签与 12 种效果）。

## 一、原版机制（反汇编实证）

- 事件共 **36 条**（id 0–35），主入口 `fcn_0044B6DF`（news.c: `news_events()`）。
- **抽签算法**：游标从当前值起在 0–35 间轮询，对每个 id 先过 `check_news()` 前提检查（如「有人坐牢」「有股票」「有人步行」），抽到第一条满足的即播出；一圈全不满足则无事发生。
- **标题栏 6 类**（指针表 0x475ED8）：无责任新闻(id0-5) / 政府公告(6-13) / 社会新闻(14-16) / 路况报道(16-17) / 气象报道(18-21) / 财经新闻(22-35)。
- 文字模板：exe 数据段 0x4653EC–0x465874，BIG5 编码，编号 #0149–#0184（**#0149+id 即事件 id**）。
- 事件画面：`Data.MKF` 块 **441+id**（388×251 报纸插图）；报纸底图：`Panel.MKF` 块 66。
- 数值常量（浮点，fistp 截断取整）：地价 ×1.3（0x4654DC）、地价 ×0.7（0x46561C）、税率 0.05（0x4655A4/CC）、存款红利 0.1（0x465734）。
- 玩家结构体（rich4_player_info.h）：+28=现金、+32=存款 → **所得税按现金 5%、存款红利按存款 +10%**。

## 三、本作接入方式

- `RichNewsData.POOL`：36 条全量（id/分类/简体文本/效果/参数/supported 开关）；`supported_pool()` 返回 12 条可用子集。
- `RichGame.chance_pool` 初始化即载入可用子集；`resolve_landing()` 机会格抽签 = 前提过滤后随机（比原版「轮询」简化，结果分布等价）。
- 抽签前提（照抄 check_news）：摧毁类需有建筑；奖励/补助/地价税需有人有地；豪雨需有人步行；交通阻塞需有人乘车；地价涨/所得税/红利/闹鬼恒可触发。
- ⚠ 原版这套池挂在**新闻格**（TILE-18）；V0 棋盘只有机会格（5/15/25/35），暂接机会格，后续加新闻格后分流并补 TILE-17 的违法事件（EVT-02）。
- 地价涨/跌通过 `RichGame._price_mult` 永久生效于买地价与租金（与原版对地价字段乘浮点、截断取整一致）。
