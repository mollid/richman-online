## 二、每日价格随机游走（FUN_004291d6，日结 FUN_0041cf67 调用）

每日日结顺序：`srand(GetTickCount())` → 本函数。伪代码：

```
大盘漂移 drift = (rand() - 0x4000) / 4097.0        # ∈ [-4.0, +4.0] 百分点
for 每支股票 i:
    开盘价 = 昨收
    if 停牌剩余(+6) > 0:  今日涨跌 = 0               # 停牌不动
    elif 趋势标志(+7) 高半字节>0: 今日涨跌 = +10.0    # 强制涨停
    elif 趋势标志(+7) 高半字节==0 且 低半字节>0: = -10.0 # 强制跌停
    else:  # 正常随机游走
        噪声  = (rand()-0x4000)/1171.0               # ∈ [-14.0, +14.0]
        涨跌(+0x1c) = 噪声 × 波动系数(+0x18) + 旧涨跌(+0x1c) + 大盘漂移
        # 均值回归：
        if 无绑定城市: 基准 = +0x0c
        else:         基准 = 城市地价 / 10000.0
        if 价格 < 基准×0.5 (腰斩): 涨跌 *= 2.0（若为正）或 ×0.5
        if 价格 > 基准×8.0 (八倍): 对称调整
        涨跌 clamp 到 [-10.0, +10.0]                  # 单日 ±10% 硬限制
    新价 = 开盘价 × (1 + 涨跌/100.0)  ± rand()×小扰动   # FUN_00428ec5
    if 新价 < 1.0: 新价 = 1.0
    if 新价 > 9999.0: 新价 = 9999.0
    收盘(+0x14) = 新价；历史环形缓冲写入
```

**要点**：涨跌幅是"昨日收盘的百分比"、单日 ±10% 封顶；个股噪声幅度(±14%)远大于大盘(±4%)；腰斩/8倍触发均值回归拉回。

## 三、涨跌停交易限制（FUN_004295ea）

```
if 现价 > 开盘价:  FUN_00428ec5(开盘,+10%) <= 现价 ? 涨停(1,禁买) : 可买(0)
if 现价 == 开盘价: 平盘(4)——买卖皆可
if 现价 < 开盘价:  跌停价 FUN_00428ec5(开盘,-10%) < 现价 ? 可卖(2) : 跌停(3,禁卖)
```

- 买进入口 `FUN_0042aee4`：停牌禁交易；返回1 → 弹「漲停無法買進！」
- 卖出入口 `FUN_0042afff`：需持仓>0；返回3 → 弹「跌停無法賣出！」
- **涨停不能追价买入、跌停不能割肉卖出** —— 与现实 A 股规则同构

## 五、分红结算（FUN_0042ba97，每 15 天触发）

日结检查 `(DAT_00497160 & 0xff) == 0xf` → 每 15 天：
1. 弹「分红」面板（Panel 资源 0x4c）
2. 对每支**有绑定城市**的股票：Σ全员持股 → 每人按 `持股/总持股` 比例从**城市分红池（+0x28）**获得现金
3. 分完后分红池清零
- 分红池来源：踩地结算 `FUN_0041d2c6(..., 5)` 的第 5 类入账等经营性现金流

## 六、买卖执行与成本

买入 `FUN_00428d2a`（实证 param_4==0 分支）：
```
成本 = 张数 × (城市地价 / 10000)          # 股票面值锚定地价
城市表+0x30（剩余流通股） -= 张数           # 供给有限
玩家现金 -= 成本                           # 买股票花现金
持仓 += 张数
持仓成本 = (旧成本值+本次成本)/总持仓        # 移动平均
```
卖出 `FUN_00428e23` 对称（入现金），另有成交记录写入 `FUN_004246c5`（每人 7 条循环覆盖）。
