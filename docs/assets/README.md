## board-svg/ · 棋盘拓扑图

`map0.svg` ~ `map7.svg`，对应 8 张地图（gid 0~7，见 `../data/README.md`）。

每张图为该地图的**节点 + 邻接连线**可视化：

- 圆点 = 棋盘节点，位置取自节点像素坐标
- 连线 = 邻接关系（棋盘拓扑：主体环路 + 支线）
- 配色 = 地价由绿到红渐变，可读出一张图的价格分布
- 标注 = 地块名

**用途**：

1. **人工核对** —— 检查节点的邻接解析是否正确（改地图数据后重新生成对比）
2. **渲染参考** —— 实现 Phaser 棋盘层时的目标形态
3. **策划看图** —— 不跑引擎也能评估地图设计

SVG 可直接在浏览器打开。若要重新生成，需要原始 `map.mkf`
（`H:\rich\C1118\Richman\Richman 4\rich4\MultiverseJourney\map.mkf`）。
